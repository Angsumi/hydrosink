## Reproduce the statistics (from per-sample outputs)
```bash
HS_ENV=/path/to/hydrosink/bin bash run_all.sh
```
Set `HS_ENV` to the installed analysis environment's `bin` directory. The script checks file integrity, rebuilds matrices and regenerates the main models, supported sensitivity analyses, tables and figures. The sequencing workflow and marker benchmark run separately.
Verified 2026-11-18: about 1 h on 16 cores; all 103 result tables byte-identical to the committed ones (`analysis/results/rerun_comparison.tsv`).
Independent model fits run in parallel. The dated-tree step uses committed TimeTree responses and requests missing ages from the API.

## Full pipeline (from public reads)
1. The scripts beginning with `01` record inventory screening, host traits, tree construction and metadata curation. The committed queue files fix the exact P1 and P2 accession sets used in the study.
2. Build the search index with `diamond makedb --in analysis/db/hydrosink.faa --db analysis/db/hydrosink`.
3. To fetch and quantify the recorded runs, use `analysis/scripts/run_queue.sh <list> <parallel> 5000000 <threads>`. Use `analysis/inventory/p1_queue.txt` with `HS_SAMPLING=head` and `analysis/inventory/p2_queue.txt` with `HS_SAMPLING=offsets`. Set `HS_ENV` to the analysis environment's `bin` directory. The queue skips existing marker tables.
4. Run the statistical workflow above. To reproduce the benchmark separately, use `analysis/bench/bench_fetch.py` and `analysis/bench/bench_all.sh`.

Tools: DIAMOND 2.1.10, fastp 0.23.4, Python 3.11, sra-tools 3.1.1, R 4.3.3 (metafor 4.8-0, lme4 1.1-37, MCMCglmm 2.36, ape 5.8-1), wgsim, NCBI datasets.
See `analysis/env/environment.yml` for the analysis environment.

## Protocol and reporting
- The initial protocol and analysis code are recorded in commits `67eb757` and `eec1a3e`. The `prereg-v1` tag marks the later Gate 1a commit. These two initial commits predate the automated co-author trailers and retain their original IDs. Later commit trailers were removed from the default branch. The original protocol and release tags still identify the archived snapshots. The study has no external registration.
- **Post-hoc analyses**, all labelled as such in the manuscript:
  - no-mouse set;
  - *acsB* taxonomic attribution, which replaced the planned read placement because reads were not retained;
  - revised benchmark scoring. The benchmark itself was planned before P2 and run after the main analyses.
- **Not done:** per-study risk-of-bias scoring and certainty-of-evidence grading (see the PRISMA checklist).
